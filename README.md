# Beckers Cup

The website of the Beckers Cup, a yearly pétanque tournament.

**[Visit the site](https://ractouf.github.io/beckers-cup/)**

## What it does

- Shows each year's tournament bracket and results, from 2022 to today.
- Photo gallery of the tournaments.
- Team maker: paste the players' names, one per line, and it draws random teams.

## Run it

It's a static site with no build step: open `index.html` in a browser.

Pushing to `master` deploys to GitHub Pages.

Built with HTML, CSS, JavaScript and Tailwind CSS.
